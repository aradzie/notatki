# @notatki/preview-assets

Builds the CSS and JS assets that style and add interactivity to the notes preview generated by
`@notatki/preview` — the flashcard list, KaTeX math rendering, and other elements shown in the preview HTML file.

## Why this package exists

`@notatki/preview` builds its preview HTML file programmatically, without a bundler, and inlines the CSS/JS needed to
style and drive it. To make those assets importable from plain TypeScript (`import CSS from
"./asset.css.ts"`), this package compiles `src/index.ts` (and the `main.css` it imports) with esbuild and writes the
result not as `.css`/`.js` files, but as generated `.ts` modules, each exporting the compiled asset as a string:

```ts
// asset.css.ts
export default "...compiled CSS...";
```

```ts
// asset.js.ts
export default "...compiled JS...";
```

These generated files are written directly into `../notatki-preview/src/` (`asset.css.ts` and `asset.js.ts`), where
`@notatki/preview` imports them and inlines their string content into the `<style>`/`<script>` tags of the preview HTML
that it builds at runtime.

Using esbuild for this step also means the preview's CSS/JS isn't limited to a single file: the functionality can be
split across multiple modules, and esbuild bundles them into one script and one stylesheet, minifying both in production
builds — the same workflow you'd get bundling for the browser, just producing a string constant instead of files served
over HTTP.
